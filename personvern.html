Personvernerklæring

Sist oppdatert: Februar 2026

MinPris.app respekterer personvernet ditt.

1. Hva vi behandler

Vi kan behandle nødvendige opplysninger som e-post, Stripe-kundeinformasjon og tekniske data (cookies/localStorage).

2. Formål

Data brukes for å levere tjenesten, håndtere abonnement og forbedre funksjonalitet.

3. Deling

Vi selger aldri data. Opplysninger kan deles med Stripe og nødvendige tekniske leverandører.

4. Lagring

Data lagres kun så lenge det er nødvendig.

5. Dine rettigheter

Du kan be om innsyn, retting eller sletting.

6. Cookies

MinPris.app bruker cookies/localStorage for funksjonalitet og brukeropplevelse.
